# KVSSD Attention v0.1.1

This patch release fixes installation and CI behavior discovered immediately after the initial public
release. It contains no storage-format or numerical changes.

## Fixed runtime dependency

The SSD codec converts contiguous PyTorch tensor buffers to and from byte-oriented views through NumPy.
NumPy was available on the development system but was not listed in the package's runtime dependencies.
Consequently, a clean Linux CI installation reached the storage tests and failed with:

```text
RuntimeError: Numpy is not available
```

`numpy>=1.24` is now declared alongside PyTorch. Fresh installations receive the complete runtime
dependency set before the codec is imported.

## CI trigger cleanup

Push CI now targets the `main` branch explicitly. Pull requests remain covered, while annotated release
tags no longer launch a redundant copy of the same CPU workflow.

## Validation

- All 12 portable tests pass locally.
- Ruff static checks pass.
- Wheel packaging passes.
- The GitHub-hosted Linux workflow validates the clean dependency installation.

## Compatibility

- On-disk format version remains `1`.
- Python API and CUDA extension ABI are unchanged from `v0.1.0`.
- Existing KVSSD stores require no migration.
- Physical NVIDIA GPU runtime validation remains a separate project milestone.
